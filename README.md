# Cronómetro para Debates Escolares - ikasNOVA

Cronómetro web interactivo diseñado para gestionar debates escolares con múltiples fases y participantes.

## 🌟 Características

- **Multiidioma**: Soporte para Español, English y Euskera
- **8 Fases de Debate**: Introducción, refutaciones y conclusiones para dos equipos
- **Tiempo Negativo**: Continúa contando en rojo cuando se agota el tiempo
- **Alertas Visuales**: Cambio de color a naranja con 30 segundos restantes
- **Exportación CSV**: Genera reportes detallados con tiempos utilizados
- **Diseño Responsive**: Funciona en ordenadores, tablets y móviles
- **Interfaz Intuitiva**: Fácil configuración de nombres y tiempos

## 🚀 Demo en Vivo

[Ver Demo](https://tuusuario.github.io/cronometro-debate/)

## 💻 Uso

1. Selecciona el idioma deseado
2. Introduce los nombres de los equipos o participantes
3. Haz clic en "Iniciar Debate"
4. Navega entre las pestañas para cada fase
5. Controla cada cronómetro independientemente
6. Exporta los resultados a CSV al finalizar
